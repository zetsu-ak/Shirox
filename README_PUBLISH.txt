PUBLISHING ON GITHUB PAGES
1. Download this ZIP and extract it.
2. Open your GitHub repository: zetsu-ak/Shirox.
3. Upload ALL files and folders inside the extracted folder to the repository ROOT (not the ZIP itself and not a nested folder).
4. Choose to replace existing files when GitHub asks.
5. Commit the changes to the branch/folder currently used by GitHub Pages (usually main / root).
6. Wait for the Pages deployment to finish, then open https://zetsu-ak.github.io/Shirox/ and refresh. If an old version remains, hard-refresh or clear the browser cache.

SECURITY LIMITATION
GitHub Pages serves public HTML/CSS/JavaScript to visitors. No front-end code can reliably prevent copying or hide secrets embedded in the site. Do not place passwords, API keys, private tokens, or confidential drafts in this repository. The Content Vault lock is a convenience UI only. Strong access control for private data requires a real authenticated backend and server-side authorization.
